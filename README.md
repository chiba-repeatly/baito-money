# バイトマネー

アルバイト向けの無料給与計算Webサービスです。

## 公開URL
https://chiba-repeatly.github.io/baito-money/

## 主な機能
- 時給・出退勤・休憩・勤務日数から日給と月収を計算
- 目標月収までの差額と必要勤務時間を表示
- 日付をまたぐ勤務に対応
- 任意で22:00〜翌5:00の深夜割増を概算

- シフト管理カレンダー（日別記録・月別の勤務時間と概算給料の集計、ブラウザ内保存）

## 技術構成
HTML / CSS / JavaScript の静的サイトで、GitHub PagesへGitHub Actionsから自動デプロイします。

> シフト記録は端末のブラウザ内（localStorage）に保存され、端末間同期されません。カレンダーでは深夜割増を含みません。

> 計算結果は概算です。時間外・休日割増、税金、手当など勤務先固有の条件は完全には反映しません。
